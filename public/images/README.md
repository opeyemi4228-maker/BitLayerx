# Site photography

Drop files here with these exact names and they appear on the site
automatically. Until then, each slot renders a branded generated plate  -  never
a stock photo standing in for something real.

Paths are declared once in `lib/media.js`.

| File                      | Where it appears        | What to shoot                                                       |
| ------------------------- | ----------------------- | ------------------------------------------------------------------- |
| `hero-work.jpg`           | Homepage hero           | Real BitLayerX work on a screen  -  a product you shipped              |
| `method-studio.jpg`       | The BitLayerX Method    | The actual team working: wall of wireframes, whiteboard, laptops     |
| `founder-opeyemi.jpg`     | Founder section         | Opeyemi, waist-up, natural light, working environment  -  not a studio backdrop |
| `practices-build.jpg`     | Practices section       | Two or three people mid-build, screens visible                       |
| `work-fintech.jpg`        | Selected work           | Screens from the payments platform                                   |
| `work-logistics.jpg`      | Selected work           | The fleet dashboard in use                                           |
| `work-property.jpg`       | Selected work           | Brand/film work for the property client                             |

## Export settings

- 2400px on the long edge
- JPEG or WebP, quality ~80
- sRGB colour profile

## The one rule

Only put a photograph here if it is a photograph of the thing it claims to be.
Real photographs of a small team beat stock photographs of an imaginary large
one  -  smallness reads as honest, and honest reads as safe to hire.
